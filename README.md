# claudiobrito.com

Site pessoal de Claudio Brito, fundador da Global Mentoring Group. Página estática (HTML e CSS, sem build), publicada no Firebase Hosting do projeto `app-antigravity-adfda`, site `claudiobrito`.

- `public/`: o site. A página inicial é `public/index.html`.
- `functions/`: a função que manda o primeiro capítulo do livro a quem pede no formulário.
- `docs/publicar.md`: passo a passo para colocar no ar.
- `docs/regras-firestore.md`: regras do Firestore do formulário.

Pull requests geram uma prévia automática; o merge na `main` publica.
